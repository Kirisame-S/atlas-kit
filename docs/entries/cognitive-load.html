IDEA 01 · 設計心理

認知負荷

Cognitive Load

認知負荷，是理解資訊與操作介面時需要投入的心智資源。設計可以減少不必要的理解成本。

FIG. 01Cognitive Load
ON THIS PAGE01 理解觀念02 看見差別03 帶走提問04 延伸來源

01 / UNDERSTAND

先理解這件事。

想像你第一次使用報名網站：需要先找到日期，再分辨方案，還得記住每個按鈕的用途。資訊本身未必困難，呈現方式卻可能增加負擔。整理資訊順序、使用清楚標籤，並在適合的時機提供細節，有助於把注意力留給真正的任務。減少負荷並不等於把所有內容刪光；必要資訊仍要在使用者需要時找得到。

02 / COMPARE

換個方式，差在哪裡？

情境：第一次報名讀書會，需要知道時間、費用與報名方式。

BEFORE / 原本的版本

讀書會即將開始！參加方案、歷年紀錄、講者簡介、活動相簿、常見問題、交通指南、贊助單位與報名入口全部擠在第一個畫面。

AFTER / 調整後的版本

週六閱讀小聚 時間：11 月 21 日 14:00 費用：免費，需事先報名 主要操作：查看場次並報名 講者與交通資訊，接著往下閱讀。

↳ 先呈現完成任務所需的核心資訊，其他內容依閱讀順序展開；日期為教學情境。

03 / TAKE AWAY

下次，可以問自己。

  • 使用者進入頁面後，能找到目前最重要的任務嗎？
  • 完成操作時，需要反覆記住前一頁的資訊嗎？
  • 延後呈現的細節，在需要的時候仍找得到嗎？
