01 / THE DESIGN SYSTEM

米白紙張、深綠重點、細線分隔、幾何海報。三組分類配色與六種圖形集中管理；卡片與內頁共用同一份資料。桌面三欄、平板兩欄、手機一欄。

02 / ADD AN IDEA

新觀念，只需要一份新資料。

  1. 先讀規則讓 AI 閱讀根目錄 AGENTS.md，理解固定欄位、視覺與驗收方式。
  2. 複製範本把 templates/entry.example.json 複製到 content/entries/，填入新內容與來源。
  3. 產生與檢查執行建置及連結檢查；首頁卡片、分類、案例頁和翻頁導覽會同步更新。
python3 scripts/build.py
python3 scripts/check.py
python3 -m http.server 8000 --directory docs

03 / TRY THIS PROMPT

把下一篇交給 AI。

請先閱讀 AGENTS.md 與 templates/entry.example.json，新增一篇「清楚的按鈕文案」圖鑑，放在「寫作練習」分類。請用原創前後對照與三項檢核問題，維持既有配色、卡片與內頁版型。使用尚未占用的 order，執行建置、連結檢查與測試，並說明修改的檔案與驗證結果。
